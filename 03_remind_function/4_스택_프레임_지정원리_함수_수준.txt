1. 스택 프레임 지정원리 - 함수 수준
    1-1. 매개변수는 오른쪽부터 스택에 Push 됩니다.
        => int add (int param1, int param2) -> param2가 아래, param1이 param2위에 배치됩니다.

    1-2. 스코프 단위로 끊어서 표시합니다. (함수는 별도 단락으로 표시)

    1-3. 함수 반환 시 해당 함수가 사용한 스택 메모리는 반환됩니다.
        => 스택 포인터가 -- ; 값은 남아 있습니다.
        => 동적할당된 포인터를 free()를 하거나 함수 반환하거나 그 메모리의 값은 0으로 사라지지 않습니다.
        => 단지, 그 공간을 사용할 수 있다고 허용합니다.
        => 스택에서는 함수가 반환되면 스택 포인터를 가지고 있는 레지스터에게 그 결과를 알려줘야 합니다.
            => 그래야 제대로 된 계산 위치를 잡습니다.
    
    1-4. 전역, 정적 변수는 스택을 사용하지 않습니다.


2. Call Stack
    2-1. 스택 프레임에서 호출 관계를 콜 스택이라고 합니다.
        => main에서 add를 call / add에서 print를 call (main -> add -> printf..)
