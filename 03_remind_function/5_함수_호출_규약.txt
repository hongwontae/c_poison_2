1. 함수 호출 규약 (Call Convention)
    1-1. 함수 호출로 증가한 스택 메모리 사용 및 관리에 관련된 규칙
        => 스택 포인터를 조정해 사용 중인 스택 공간을 회수하는 작업입니다.
        => 즉, 값을 초기화하는게 아니고 스택 포인터 위치를 아래로 내립니다.
        => 이러면 다음 함수가 호출되면 스택 포인터 위치가 올라갑니다. -> 공간을 회수
    1-2. __cdecl (호출자가 스택 정리)
    1-3. __stdcall (피호출자가 스택 정리)
    1-4. __fastcall (매개변수에 레지스터 사용)
        => 매개변수를 레지스터에 넣어서 사용하기에 스택 포인터를 조정하지 않아도 됩니다.
    1-5. int __cdecl add (int param_1, int param_2);
        => 함수 호출 규약이 존재해야 합니다.
        => 그러나 생략하면 __cdecl을 default로 정의합니다.


2. 스택 포인터 흐름
    2-1. 스택 포인터는 메모리의 주소를 가리킵니다.
    2-2. 지역 변수 정리는 지역 변수를 정의한 함수에서 실행합니다.
        => 사용한 데이터에 의해 스택 포인터 증가 -> 반환될 떄 스택 포인터를 내려야 함
    2-3. 매개변수는 함수 호출 규약에 따라 호출자 | 피호출자가 스택 포인터를 감소시켜야 합니다.
    2-4. 매개변수가 레지스터에 존재하면 Stack을 사용하지 않습니다.
        => 그렇기에 스택 포인터에 영향을 주지 않고 함수가 반환될 떄 esp- esp+을 하지 않습니다.
