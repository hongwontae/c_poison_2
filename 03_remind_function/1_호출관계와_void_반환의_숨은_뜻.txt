1. 호출관계
    1-1. c 프로그램은 main 함수를 시스템이 호출해줍니다.
        => 모든 연산의 출발점은 main입니다.
    1-2. 함수를 호출하는 함수를 호출자 함수/ Caller라고 부릅니다.
    1-3. 호출을 당하는 함수를 피호출자 함수/ Callee라고 부릅니다.
    1-4. 호출자는 피호출자의 매개변수의 값을 정의해야 합니다. -> 호출자의 의무
    1-5. 함수 내부에서 함수를 실행해서 호출자 - 피호출자 관계가 성립된 뒤에
        피호출자 함수에서 다시 함수를 호출해서 Caller이자 Callee가 되었습니다.
        => 이 떄 맨 처음 호출자 함수는 피호출자 함수가 Caller이자 Callee가 된 관계에 대해서 고려하지 않습니다.


2. void 반환의 숨은 뜻
    2-1. Caller는 Callee의 제어의 흐름이 갔다가 되돌아오는 것에만 중요합니다.
    2-2. void : return 값을 받지 않겠다. && call에서 callee의 success나 failure에 대해서 고민하지 않겠다.


3. 함수 내부에서 함수를 call를 부르는 행위 -> 제어의 흐름이 변경됩니다.
    => 이러한 동작을 문맥 교환이라고 합니다.
