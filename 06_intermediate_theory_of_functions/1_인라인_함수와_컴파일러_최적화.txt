1. 인라인 함수와 컴파일러 최적화
    1-1. 함수 호출 시 스택 증/감 및 매개변수 복사 등 부가적 코드 수행에 따른 오버헤드 발생합니다.
        => 함수 호출 그 자체로 CPU와 RAM을 사용합니다.
    1-2. 컴파일러가 불필요한 오버헤드 제거를 위해 코드 상 존재하는 Callee의 코드를 
            Caller에 포함시켜 실제로는 호출하지 않도록 최적화합니다.
    1-3. 현대의 컴파일러는 함수 Caller와 Callee를 분석해 자동으로 최적화합니다.
        => 읽기 좋은 코드 -> 가독성이 높은 코드 -> 현대에서는 함수로 뺼 수 있다면 뺴는 게 효율적인 방법 -> 컴파일러가 자동으로 최적화
    1-4. __inline 반환형 이름 () {}
        => 이러한 인라인 키워드를 사용하는 함수는 1-3을 하라고 명시적으로 알려주는 것입니다.
        => 이러한 인라인 키워드가 존재하더라고 최적화 여부는 컴파일러가 정합니다.
    

2. main 함수 내에서 add(3,4)를 호출한다면?
    => add 함수가 return a+b;
    => 컴파일러가 callee를 보고 add 함수 자체를 caller에 넣어 버려 실행시킵니다.
    => 함수 호출에 의한 오버헤드를 자체적으로 줄여버립니다.
