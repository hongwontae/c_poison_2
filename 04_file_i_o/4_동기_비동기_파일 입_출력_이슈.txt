1. 동기 입출력
    => 파일 읽기 요청 -> 읽기 작업이 반환될 떄까지 기다림 -> fread() 반환 -> "읽기 완료" 출력
    => 즉, fread()가 데이터를 읽어 반환하기 전까지 스레드는 다음 코드로 넘어가지 않습니다.


2. 비동기 입출력
    => 입출력 작업을 요청한 뒤에 작업이 완료되기 전에 호출한 쪽이 다른 일을 할 수 있는 구조입니다.
    => 스레드가 입출력 작업을 요청하고 빠져나와서 다른 코드를 실행하는 구조입니다.


3. 동기와 비동기는 호출한 쪽이 어떻게 움직이느냐에 따라서 나뉠 수 있습니다.
