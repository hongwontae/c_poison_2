1. 텍스트와 바이너리의 차이
    1-1. 텍스트는 바이너리의 일종이며 이는 ASCII 코드가 정수로 해석될 수 있는 것과 같은 원리입니다.
    1-2. -1에 대한 해석(EOF)가 다릅니다.

    1-3. 텍스트 파일은 바이트를 문자 인코딩 규칙에 따라 해석하는 파일입니다.
        => ABC를 파일에 저장 -> unicode 코드 포인트 -> UTF-8 인코딩 -> 41 42 43 바이트 저장
    
    1-4. 바이너리 파일은 특정한 형식에 따라 바이트를 해석하는 파일입니다.
        => 파일 형식에 따라 이진 데이터로 저장하고 해석합니다.
        => 이미지 -> png 이진수 변환 규칙에 따라 이진수로 변환 -> 저장 -> 꺼낼 떄 png 형식에 의해 해석 -> 사진 보여줌


2. File Stream
    2-1. 프로그램이 파일 데이터를 읽고 쓰기 위해 사용하는 추상적인 인터페이스입니다.
    2-2. 데이터를 전달 하는 통로이며 C의 FILE 객체는 버퍼, 파일 끝 상태, 오류 상태 등의 정보도 관리합니다.
