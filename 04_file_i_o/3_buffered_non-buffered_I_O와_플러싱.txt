1. CON
    1-1. Windows에서 CON은 콘솔을 가리키는 특수한 이름입니다.
    1-2. FILE *fp = fopen("CON", "r"); -> 디스크 파일을 여는게 아니라 콘솔 입력 장치 연결입니다.
        => 파일이라는 이름으로 접근은 가능하나 디스크에 저장된 파일은 아닙니다.
        => OS가 파일과 비슷한 인터페이스 장치 기능을 제공하는 것입니다.


2. 장치 (device)
    2-1. 컴퓨터와 데이터를 주고받거나 특정 기능을 수행하는 하드웨어를 의미합니다.
    2-2. 프로그램이 키보드 입력을 받고 싶다면
        => C 프로그램 -> 운영체제 커널 -> 장치 드라이버 -> 키보드 하드웨어
    2-3. 장치 드라이버 : 운영체제가 특정 하드웨어와 통신할 수 있도록 해주는 프로그램


3. 파일을 fopen()으로 열고 fread(), fwrite() 같은 함수를 사용하면 시스템 콜인 read, write()가 실행됩니다.
    => 시스템 콜이 호출되면 커널에 접근해서 요청을 가할 수 있습니다.


4. 파일은 항상 버퍼와 함께 존재합니다.
    4-1. 버퍼를 채워넣는 행위를 버퍼링이라고 합니다.
    4-2. 버퍼 -> 입출력 데이터를 잠시 모아 두는 메모리 공간입니다. Input Buffer / Outpu Buffer가 존재합니다.
    4-3. fopen()으로 파일을 열면 스트림을 관리하기 위한 FILE 객체를 준비합니다.
        => 스트림 상태와 버퍼 관련 정보등을 관리합니다.
        => 일반적인 C 프로그램에서는 FILE 객체와 입출력 버퍼가 사용자의 공간에 존재합니다.
    4-4. 파일을 fget('')으로 읽을 떄 전부 버퍼라는 공간에 가져오고 하나씩 가져옵니다.
        => 즉, 파일 스트림을 통해 가져오는게 아니고 버퍼라는 공간을 먼저 확인합니다.
    4-5. 파일을 fputc()로 쓸 떄는 바로 저장하는게 아니라 출력 버퍼에 저장하고
            버퍼가 가득 차거나, fflush(), fclose()가 호출되면 데이터를 실제 파일로 전달합니다.
    4-6. FILE 객체는 파일 디스크립터, 입출력 버퍼의 주소, 버퍼의 크기, 버퍼에서 읽거나 쓸 위치를 나태는 정보가 있습니다.
