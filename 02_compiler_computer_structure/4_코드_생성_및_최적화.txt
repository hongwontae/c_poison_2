1. 코드 생성 및 최적화
    1-1. IR로부터 어셈블리어 등 기계어에 대응될 수 있는 쉬운 명령어 연속(집합)으로 변환합니다.
        => 어셈블리어 -> 기계어를 사람이 알아볼 수 있는 형태로 변환한 것입니다.
        => 코드 제네레이터가 만들어내는 산출물은 어셈블리어입니다. -> 그 과정에서 최적화가 실행됩니다.
        => int a = 3+4; -> int a = 7 -> 이렇게 최적화 
        => 상수 접기(Constant Folding) : 상수를 프로그램 실행 시점이 아닌 컴파일 시점에 미리 수행해
            코드를 최적화하는 것을 의미합니다.
    1-2. 기계어 변환에 앞서 불필요한 코드를 제거하는 등 최적화 작업을 실시합니다.


2. 보편적 의미와 최적화
    2-1. 불필요한 연산 제거
        => 변수에 대한 의존관계 분석
        => 불필요한 상수연산을 결과로 대체 -> 상수 접기
        => 반복문 내부 불필요한 코드 제거
    2-2. 함수 호출이 필요 없도록 inline화
        => 함수 호출에 의한 오버헤드
            -> 함수 호출 준비 : 인자 전달, 필요한 레지스터나 스택 상태 처리
            -> 함수로 이동 : 반환 후 위치를 보존하고 add 함수 실행
            -> 함수 실행 후 복귀 : 결과를 반환하고 호출한 위치의 실행을 재개
        => 이러한 준비와 복귀 작업은 시간과 자원이 요구되고 이 추가 비용을 함수 호출 오버헤드라고 합니다.
        => 컴파일러가 이러한 오버헤드를 줄이기 위해 인라인으로 만들 수 있습니다.
        => main에서 add 함수 call -> 근데 단순히 + 연산하고 return -> main에서 풀어버림
