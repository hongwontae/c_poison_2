1. 컴파일러 구성요소
    1-1. 어휘 분석기 (Lexical analyzer) (Token)
        => 어휘 분석기를 Scanner라고도 합니다.
        => 프로그램 -> 절차적인 글쓰기로 볼 수 있습니다.
        => C언어 파일을 C언어 문법 규칙에 따라 잘라내는 역할을 담당합니다.
        => 이러한 작업을 toknenize라고 합니다.
    1-2. 구문 분석기 (Syntax analyzer) (Syntax Tree, Abstract, Decoration)
        => 구문 분석기를 Parser라고도 합니다.
        => 토큰들의 구조를 분석해 구문 트리 같은 자료구조를 만듭니다.
        => 구문 트리를 만드는 과정에서 C 언어의 문법 규칙에 맞게 작성되었는지 검사합니다.
        => int age = 20; int/ age/ = / 20/ ;
        => 구문 분석기가 토큰들을 C 문법 규칙에 따라 분석 -> 문법 올바름 -> 구문 트리로 만듬
    1-3. 의미 분석기 (Semantic analyzer) (Intermediate Repressentation)
        => 문법적으로 올바른 코드가 의미적으로 유효한지 검사하는 단계입니다.
        => 구문 분석기가 만든 구문 트리를 바탕으로 코드의 의미가 올바른지 검사합니다.
        => int age = "hello"; -> 변수 선언 문법 자체는 맞아서 구문 분석기는 통과
            -> 의미적인 규칙이 다름 -> int에 문자열 -> 에러로 처리합니다.
        => 변수 선언 여부, 자료형의 호환성, 함수 호출 인자.. 등 검사합니다.
