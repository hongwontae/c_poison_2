1. 정적/동적 라이브러리 
    1-1. 라이브러리는 쉽게 생각해 함수만 따로 모은 실행 파일
    1-2. 함수라는 표현보다 API라고 부르는 경우가 많고 특정 환경에 맞춘 종합적인 API 묶음을 SDK라고 합니다.
    1-3. 정적 라이브러리 확장명 -> lib / a
        => 실행 파일과 link시 결합되어 하나의 실행파일로 합성됩니다.
    1-4. 동적 라이브러리 확장명 -> dll / .so
        => 실행 파일과 link시 하나로 합쳐지지 않고 독립적인 실행파일 형태로 생성되며 
            실행 파일이 될 떄 런타임에 결합합니다.
