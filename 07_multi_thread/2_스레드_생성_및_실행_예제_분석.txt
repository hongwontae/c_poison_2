1. beginthread()
    1-1. 스레드를 생성하고 실행하는 함수입니다.
    1-2. 첫 번쨰 인자는 함수 포인터
    1-3. 두 번째 인자는 stack_size (대체로 0을 주면 컴파일러가 알아서 넣어줍니다.)
    1-4. 세 번쨰 인자는 함수 포인터의 매개변수


2. main 함수를 실행시키는 스레드를 main 스레드,
    메인 스레드에서 실행되는 스레드를 worker 스레드라고 합니다.


3. 스레드를 생성하면 비용이 증가합니다.
    => CPU, RAM..를 사용합니다.


4. main 함수가 실행되고 main 내에서 스레드를 생성하고 실행했습니다.
    4-1. 이렇게되면 main thread() worker thread()가 동시에 실행되고 있는 것입니다.
    4-2. 만약 main thread가 worker thread()보다 빠르게 끝나서 return 0을 만나면
            worker thread의 작업 흐름이나 종료 상황을 보지 않고 프로세스가 종료됩니다.
    4-3. 이를 terminate라고 합니다.


5. 스레드를 생성하는 비용은 비쌉니다.
    => main 함수에서 worker_thread를 생성하고 실행
    => main 함수에서 for문으로 1500000~2000000 연산을 기다려야 worker_thread가 끝나는 모습 포착
    => 대체로 동시성을 갖추는 서버는 thread 자체를 먼저 생성하고 요청이 존재할 떄 실행하는 구조로 사용합니다.
