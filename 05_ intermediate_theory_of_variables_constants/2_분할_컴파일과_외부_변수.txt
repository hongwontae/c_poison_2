1. 분할 컴파일과 외부 변수
    1-1. 한 프로젝트 묶음에 여러 소스 코드 파일을 두고 코드를 분할합니다.
    1-2. 개별 .c 파일은 구별된 .obj(목적 파일)을 생성합니다. 목적 파일을 모듈이라고도 부릅니다.
        => Link 작업 이후 .exe -> 즉, 하나의 실행파일이 나옵니다.
    1-3. 보통 전역 변수라는 것은 개별 .c 파일들 전체에 적용될 수 있다는 것입니다.
    1-4. 변수의 선언과 정의를 명확히 분리해야 합니다.
        => 선언은 .h 파일 / 정의는 .c 파일


2. 전역 변수와 static과 extern 키워드
    2-1. 전역 변수
        1. 함수 바깥에서 선언한 변수를 전역 변수라고 합니다.
        2. 프로그램 실행 동안 존재
        3. 선언된 위치부터 해당 소스 파일 범위에서 사용 가능
        4. 명시적으로 초기화하지 않으면 0으로 초기화
        5. 초기화된 전역 변수는 .data / 0으로 초기화 || 초기화 x 전역 변수는 .bss 영역에 존재합니다.
        6. 전역 변수라고 해서 프로그램의 모든 소스 코드 파일에서 자동으로 접근 가능하지 않습니다.
    
    2-2. static 키워드
        1. 함수 내부에서 사용하는 static
            => static이 붙은 변수는 정적 변수라고 합니다.
            => 프로그램 실행동안 저장 공간을 가집니다.
            => 명시적으로 초기화하지 않으면 0 초기화
            => 접근 범위는 함수 내부입니다.
        2. 함수 외부에서 사용하는 static
            => 전역 정적 변수라고 합니다.
            => 프로그램 동안 저장 공간을 가지고 명시적으로 초기화하지 않으면 0초기화
            => 접근 범위는 소스 파일 내부입니다. -> 다른 곳에서 extern으로 가져올 수 없습니다.
        3. 함수에도 static 키워드를 붙일 수 있습니다.
            => 파일 내부에서만 사용가능
        
    2-3. extern 키워드
        => 다른 곳에 정의된 전역 변수나 함수를 현재 소스 파일에서 사용하고 싶을 때 사용하는 키워드입니다.
        => 전역 변수를 접근할 떄 extern 키워드를 사용해야 가져옵니다.
