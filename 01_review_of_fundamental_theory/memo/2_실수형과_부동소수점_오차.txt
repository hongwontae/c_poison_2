1. 실수형과 부동소수점 오차
    1-1. float(단정도, 32bit)
        => 유효 자릿수 : 소수점 이하 6자리
    1-2. double(배정도, 64bit)
        => 유효 자릿수 : 소수점 이하 15자리
    1-3. long double (특수정도, 79bit)
    1-4. 컴퓨터에서 부동 소수점이라는 것은 필연적으로 오차를 가집니다.
        => 1/3 -> 0.33333 -> 변수는 size를 갖고 그 size만큼 데이터가 들어갑니다.
            -> 이 떄 size를 넘어서면 끊어야 합니다. -> 그만큼 오차가 발생합니다.

2. c언어에서 소수을 값으로 주면 자동으로 double 리터럴이됩니다.
    => 뒤에 F를 붙으면 float 리터럴이 됩니다.


3. IEEE 754 single format (32bit)
    3-1. 1bit Sign bit -> 0 양수, 1 음수
    3-2. 8bit 지수
    3-3. 23bit 가수


4. 123.125F를 IEEE 754 형식변환_1
    4-1. SIGN 비트 0 | 1 
    4-2. 123은 1111011 -> 2로 나누고 나머지를 나열
    4-3. 0.125 001 -> 2를 곱해 정수 값이 있으면 1
        => 0.125 * 2 = 0.25  0
        => 0.25 * 2 = 0.5    0
        => 0.5 * 2 = 1.0     1 -> 정수가 나오면 1뺴기
        => 0.0 * 2 = 0.0.. X
    4-4. 1111011.001


5. 123.125F IEEE 형식변환_2
    5-1. 1111011.001을 정규화하면 1.11101001 2^6 지수는 6
    5-2. 지수 6에 대해 32비트 단정도형 Bias(127)를 더하면 133 -> 이진수 -> 1000 0101
    5-3. 지수를 구하는 공식입니다.


6. 123.125F IEEE 형식변환_3
    6-1. 1.111011001에서 가수부터 1110 1100 1000 0000 000
        => 이렇게 23비트 변환 -> 가수
    6-2. 0100 0010 1111 0110 0100 0000 0000 0000
        => 0x42F64000 -> 리틀엔디안에서 0x0040F642


7. IEEE 754 double format
    7-1. Sign 1 bit 
    7-2. 지수 11bit
    7-3. 가수 52bit


8. 실수형과 부동소수점 오차
    => 오차가 발생하기에 == 동등 연산자를 사용하면 제대로 된 계산이 안됩니다.
    => > < 연산을 통해 오차 인정 범위를 구해서 계산해야 합니다.
